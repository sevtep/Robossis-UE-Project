# Robossis Unreal Engine Project

![Robossis Robot](Robotsc.png)

This is the Robossis Unreal Engine project.

The UE project is located in `ArmSim/`.

## Purpose

This project will be used for haptic controller and robot arm simulation.

## Structure

| Path | Description |
|------|-------------|
| `ArmSim/ArmSim.uproject` | Unreal Engine project file |
| `ArmSim/Config/` | Project configuration files |
| `ArmSim/Content/` | Game assets and content |

## Notes

- Generated Unreal folders (`DerivedDataCache/`, `Intermediate/`, `Saved/`, `Binaries/`) are ignored by Git.
- Git LFS is used for large UE assets (`.uasset`, `.umap`, `.fbx`, `.png`, `.wav`, etc.).
